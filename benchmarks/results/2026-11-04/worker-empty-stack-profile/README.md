This exploratory source-level experiment compares the unoptimized worker at revision `146d927195aa3530ee64902e442ea123fc5b5016` with an in-process guard that skips cleanup Task creation when the framework-owned AsyncExitStack has no callbacks. It does not modify tracked runtime source and does not include networking. The median direct-Worker rates were 51,719 and 81,413 requests/second across three alternating pairs. This does not attribute the complete HTTP performance difference or establish a performance acceptance result.

The JSON records each run and separate profiler summaries. Constructor counts show scheduling and allocation-related work; no heap-byte allocation profiler was used. To reproduce the comparison, use an unoptimized checkout of the stated revision, save `profile_worker.source.txt` as a Python script, and run with the checkout Python directory on PYTHONPATH while pinned to CPU0. A checkout with the optimization already applied does not provide the original baseline.
