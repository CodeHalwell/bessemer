# Retained candidate: independent final audit

The final Mac dataset (`retained-comparison/raw.json`) has 69/69 HTTP and 9/9 auxiliary cells. Of 69 HTTP cells, 67 are comparison eligible; two FastAPI scaling warmups had 1,183 transport errors and were excluded. The measured windows completed 10,104,177 correct responses with zero transport, status, or body-length errors and clean server shutdowns. The candidate wheel/native hashes match preflight and postflight: `c50f922f3deddf3fd0a993cb9396e42a70a808565a040a3e8911ff79bd59f2ca` / `67ddd7150d0f0845c2592e95bf2a3cddf5795fecf9646fccce077da8e7ac836e`. The local RC3 native comparison uses `cdd59de4b152df186780102b5133cedf96e270d22d28fafef2cb28836f677743` from the same compiler. The rejected body-frame trial is excluded.

In two paired Mac core rounds, model-256 successful-RPS ratios were 1.120 and 1.133, with CPU cost ratios 0.880 and 0.877. Large-body echo ratios were 0.779 and 0.989, so the retained patch did not establish an upload gain. JSON ratios were 0.852 and 0.992; other core routes were near parity across pairs. The one-round matched JSON/echo offered-load cases each delivered parity. See `paired-mac.svg` for each paired RPS, CPU, and RSS result; small round counts and variable host conditions limit attribution.

The retained finite-burst probe completed 8/8 runs with all jobs successful. Four candidate/baseline makespan ratios were 0.895, 0.884, 0.911, and 0.916, or 8.4–11.6% shorter in this synthetic 32-job, 50-ms blocking case; observed peak threads were 12 versus 8.

The separate Linux retained-wheel qualification completed six clean samples and three clean server sessions, with no measured or warmup errors. With four server vCPUs, four client vCPUs, 256 connections, and one shot per worker count, native RPS was 424,775 / 771,904 / 1,049,662 and JSON RPS 318,731 / 635,404 / 873,735 at 1/2/4 workers. Thus the observed 1-to-4 ratios were 2.47 and 2.74, respectively, under this topology. This is a scaling probe, not an exact capacity estimate.
